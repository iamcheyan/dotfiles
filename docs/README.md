# Dotfiles 文档

站点由 `site/build.py` 生成，视觉遵循 Cheyan Design System（CDS）：1120px 内容宽度、
Rubik/Noto Sans 回退字体、两行页眉、红色空心章节标记与浅灰画布。文档架构仍是左侧章节导航 +
右侧正文；构建和页面结构见 [本站的构建与发布](site/pages/maintenance/site.md)。

- [终端统一配色标准](site/pages/configs/theme-standard.md)：Neovim Blue / Nostalgia 的颜色角色、色值与终端映射；新增或修改工具主题时以此为准。
- [Zsh 交互式命令行工具](ZSH-CLI-TOOLS.md)：forgit 和 Pet 的安装、集成、快捷键与使用方法。
- Neovim 文档位于 [`config/nvim/docs/`](../config/nvim/docs/README.md)。
