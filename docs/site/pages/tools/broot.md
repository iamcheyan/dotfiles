# broot

## 用途

`broot` 显示目录树，让你在树里移动、预览、搜索、执行操作。它不是全屏文件管理器，而是「先看结构，再决定去哪」。

本仓库在 `zshrc` 里生成 `br` shell 函数：

```zsh
if command -v broot >/dev/null 2>&1; then
    eval "$(broot --print-shell-function zsh)"
fi
```

`br` 比直接 `broot` 多一个能力：退出时把当前目录传给 shell。

## 来源与安装

| 项目 | 说明 |
|---|---|
| 来源 | Zinit，按 OS/架构选择 Release 包 |
| 可执行名 | `broot` |
| shell 函数 | `br`，启动时由 broot 自己生成 |

```zsh
if [[ "$OSTYPE" == "darwin"* ]]; then
  zinit ice as"command" from"gh-r" bpick"broot_*.zip" mv"broot_*/aarch64-apple-darwin/broot -> broot" pick"broot"
else
  case "$(uname -m)" in
    aarch64|arm64)
      zinit ice as"command" from"gh-r" bpick"broot_*.zip" mv"broot_*/aarch64-unknown-linux-gnu/broot -> broot" pick"broot" ;;
    armv7l|armv7)
      zinit ice as"command" from"gh-r" bpick"broot_*.zip" mv"broot_*/armv7-unknown-linux-gnueabihf/broot -> broot" pick"broot" ;;
    *)
      zinit ice as"command" from"gh-r" bpick"broot_*.zip" mv"broot_*/x86_64-unknown-linux-gnu-glibc2.28/broot -> broot" pick"broot" ;;
  esac
fi
zinit light Canop/broot
```

broot 的 release 是 zip，内部按架构分了多层目录，`mv` 规则把二进制抽出来。

## 首次使用

```bash
broot
```

首次启动会引导你安装 shell 函数（`br`）。本仓库已经在 `zshrc` 里自动生成，所以通常不需要手动装。

## 基本用法

```bash
br                  # 从当前目录打开树
br ~/dotfiles       # 从指定目录
br -s               # 显示文件大小
br -p               # 显示权限
br --sizes --dates  # 多列信息
broot               # 不带 shell 函数，退出后不切目录
```

按 `Esc` 退出模糊模式回到树视图。

常用自定义：

本仓库不提供该配置，用上游默认值。

## 与 ranger / vifm 的分工

| | broot | ranger | vifm |
|---|---|---|---|
| 形态 | 树状浏览 | 双栏（三栏） | 双栏 |
| 强项 | 看结构、模糊搜索 | 预览、批量操作 | Vim 键位 |
| 退出切目录 | `br` + `:cd` | `ra` 自动 | `v` 自动 |
| 资源占用 | 低 | 中 | 低 |

想快速看清目录结构用 broot，要做批量文件操作用 ranger，要 Vim 键位用 vifm。

## 排错

**`br: command not found`**：`zshrc` 里那段 `eval "$(broot --print-shell-function zsh)"` 没执行。确认 `command -v broot` 有输出。

**`br` 退出后没切目录**：忘了在 broot 里执行 `:cd`。`br` 只在你显式 `:cd` 时才切换。

**树加载慢**：大目录默认全展开。用 `-d` 限制深度，或在配置里设 `max_depth`。

**图标乱码**：字体不是 Nerd Font。

**权限错误**：broot 默认不显示无权限目录的内容。用 `sudo broot` 或配置里放宽。

# broot

## Purpose

`broot` shows a directory tree and lets you move, preview, search, and act within it. It is not a full-screen file manager but a "look at the structure first, then decide where to go" tool.

This repo generates the `br` shell function in `zshrc`:

```zsh
if command -v broot >/dev/null 2>&1; then
    eval "$(broot --print-shell-function zsh)"
fi
```

`br` has one extra ability over plain `broot`: on exit it passes the current directory back to the shell.

## Troubleshooting

**`br: command not found`**: the `eval "$(broot --print-shell-function zsh)"` block in `zshrc` did not run. Confirm `command -v broot` produces output.

**Directory not changed after leaving `br`**: you forgot to run `:cd` inside broot. `br` only changes directory when you explicitly `:cd`.

**Slow tree loading**: large directories are fully expanded by default. Limit depth with `-d` or set `max_depth` in the config.

**Garbled icons**: your font is not a Nerd Font.

**Permission errors**: broot does not show the contents of directories you cannot read by default. Use `sudo broot` or relax it in the config.

`broot` はディレクトリツリーを表示し、その中を移動・プレビュー・検索・操作できます。フルスクリーンのファイルマネージャではなく、「まず構造を見てからどこへ行くか決める」ためのツールです。


## トラブルシューティング

**`br: command not found`**：`zshrc` 内の `eval "$(broot --print-shell-function zsh)"` の部分が実行されていません。`command -v broot` に出力があるか確認してください。

**`br` を抜けてもディレクトリが変わらない**：broot 内で `:cd` を実行し忘れています。`br` は明示的に `:cd` したときのみディレクトリを切り替えます。

**ツリーの読み込みが遅い**：大きなディレクトリはデフォルトで全展開されます。`-d` で深さを制限するか、設定で `max_depth` を指定してください。

**アイコンが文字化けする**：フォントが Nerd Font ではありません。

**権限エラー**：broot はデフォルトで読み取り権限のないディレクトリの内容を表示しません。`sudo broot` を使うか、設定で緩和してください。
