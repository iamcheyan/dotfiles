# Visual Multi：逐行扩展选择

## 目标行为

`Ctrl+N` 在插入模式中负责把当前光标／选择逐行扩展到下一行，便于在多行相同位置同时输入：

- 光标位于行首时，按 `Ctrl+N` 在下一行行首增加光标；重复按键继续向下增加。
- 光标位于行尾时，按 `Ctrl+N` 在下一行行尾增加光标；新建后将所有光标对齐到各自行尾，因此不同长度的行也能一起编辑。
- 如果 Visual Multi 正处于扩展选择模式，`Ctrl+N` 将当前选择形状向下一行延伸；因此从一处行尾到下一行行首的跨行选区可以按相同形状逐行扩展。
- 原有普通模式／可视模式下的 `Ctrl+N` 继续执行 Find Under，逐个选择相同单词。

## 实现方式

Visual Multi 的 `Add Cursor Down` 和 `Select Cursor Down` 命令本身工作在普通模式。插入模式映射用 `<C-o>` 执行一次对应的普通模式命令，随后 Neovim 返回插入模式。处于 Visual Multi 扩展选择模式时选择 `Select Cursor Down`；其他情况下选择 `Add Cursor Down`。行尾增加光标后，再调用插件的 `VM-I-End` 插入模式动作，把各光标移到各自行尾，处理不等长行。

插件文档说明，`Add Cursors Down/Up` 会按垂直列创建光标，`Select Right/Left` 会扩展所有活动选区。此处将同一垂直扩展机制绑定到插入模式的 `Ctrl+N`，保留原有普通／可视模式的 Find Under 绑定。

## 快捷键

| 模式 | 按键 | 行为 |
|---|---|---|
| 插入 | `Ctrl+N` | 在下一行增加光标，或在 Visual Multi 扩展模式下延伸选择 |
| 普通／可视 | `Ctrl+N` | 选择光标下的单词及后续匹配项 |
| 普通 | `Ctrl+J` / `Ctrl+K` | 在下方／上方增加光标 |
