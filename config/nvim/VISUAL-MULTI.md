# Visual Multi：逐行扩展选择

## 目标行为

`Ctrl+N` 在插入模式中负责把当前光标／选择逐行扩展到下一行，便于在多行相同位置同时输入：

- 光标位于行首时，按 `Ctrl+N` 在下一行行首增加光标；重复按键继续向下增加。
- 光标位于行尾时，按 `Ctrl+N` 在下一行行尾增加光标；新建后将所有光标对齐到各自行尾，因此不同长度的行也能一起编辑。
- 如果 Visual Multi 正处于扩展选择模式，`Ctrl+N` 将当前选择形状向下一行延伸；因此从一处行尾到下一行行首的跨行选区可以按相同形状逐行扩展。
- 原有普通模式／可视模式下的 `Ctrl+N` 继续执行 Find Under，逐个选择相同单词。

## 实现方式

- **行尾扩展**：检测插入模式光标处于行尾时，使用 Visual Multi 的位置添加机制（`add_cursor_at_pos`）在当前行尾与下一行行尾分别创建光标，并调用插件的 `Insert.key('A')` 进入行尾插入模式；后续连续按 `Ctrl+N` 会自动沿现有选区底部向下一行行尾追加光标并对齐。由于基于各行真实的 `$` 末尾定位，不同行长的行也能精准落在各自行尾，不会出现垂直列对其导致的短行跳过或长行错位。
- **行首扩展**：光标处于行首第 1 列时，同样在每行第 1 列定位并调用 `Insert.key('i')`，连续向下添加行首光标。
- **选区延伸 / 普通位置**：处于 Visual Multi 扩展模式时使用 `VM-Select-Cursor-Down` 延伸选区；处于行中间普通位置时使用 `<C-o><Plug>(VM-Add-Cursor-Down)` 保持垂直列加光标。

## 快捷键

| 模式 | 按键 | 行为 |
|---|---|---|
| 插入 | `Ctrl+N` | 在下一行增加光标，或在 Visual Multi 扩展模式下延伸选择 |
| 普通／可视 | `Ctrl+N` | 选择光标下的单词及后续匹配项 |
| 普通 | `Ctrl+J` / `Ctrl+K` | 在下方／上方增加光标 |
