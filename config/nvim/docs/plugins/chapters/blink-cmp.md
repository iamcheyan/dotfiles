# blink.cmp

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

提供 LSP、路径、代码片段、当前缓冲区和命令行补全。

## 在当前配置里怎么用

输入时自动显示候选；方向键选择，Enter 或 `<C-y>` 接受；Tab/Shift-Tab 在候选和 snippet 占位符间移动；`<C-space>` 手动触发，Esc 关闭。命令行输入 `:`、`/` 时也能补全。

## 动手练习

打开 Lua 文件输入 `vim.`，用方向键选补全并 Enter；输入函数 snippet 后按 Tab 逐个填写占位符；再运行 `:edit ` 观察路径提示。

## 注意事项

补全来源随语言服务器和当前上下文变化。COBOL 固定格式另有按键适配；如果 Enter 被补全菜单接管，可用 `<C-y>` 明确接受。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
