# nvim-hlslens

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

显示 Vim 搜索结果数量和当前匹配位置。

## 在当前配置里怎么用

使用 `/词` 搜索后按 `n`/`N` 遍历；也可用 `*`/`#` 搜索光标词、`g*`/`g#` 搜部分匹配。搜索计数会在匹配处显示。

## 动手练习

在长文件里搜索一个重复词，观察计数和第几个匹配；按 `n`、`N` 看位置变化；按 Esc 或 `:nohlsearch` 清除高亮。

## 注意事项

它增强 Vim 搜索；项目全文搜索仍使用 `<leader>fg` 的 Snacks picker。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
