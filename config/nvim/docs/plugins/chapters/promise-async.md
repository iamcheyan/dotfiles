# promise-async

> 公开依赖 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

为 nvim-ufo 提供异步 Promise 工具，避免折叠计算阻塞界面。

## 在当前配置里怎么用

无需手动调用或配置。它作为 nvim-ufo 的依赖随插件加载；折叠操作仍使用 Vim 的 `z` 系列按键。

## 动手练习

打开一份支持折叠的代码，按 `zM`/`zR` 体验折叠；这就是验证它所在功能链的方式。不要尝试通过 `:Promise` 等命令调用它。

## 注意事项

属于库型依赖，没有独立用户界面。只有删除依赖它的上层插件时，才评估是否移除。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
