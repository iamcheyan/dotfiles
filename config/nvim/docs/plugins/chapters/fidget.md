# fidget.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

显示 LSP 服务器正在索引、检查或处理请求的进度。

## 在当前配置里怎么用

自动显示，不需命令。打开大型项目或首次加载语言服务器，观察右下方进度通知；结束后通知会消失。

## 动手练习

打开一个已配置 LSP 的文件，等待服务器初始化或触发一次代码操作；观察是否出现进度提示。

## 注意事项

没有 LSP 附加、任务很快完成或服务器不报告进度时，不会显示内容。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
