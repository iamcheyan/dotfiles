# vim-visual-multi

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

在多个位置同时编辑重复文本或同列内容。

## 在当前配置里怎么用

Normal/Visual 按 `<C-n>` 选择光标下单词并逐个增加下一个匹配；`q` 跳过匹配，`Q` 回到前一个，Esc 退出；`<C-j>`/`<C-k>` 加下方/上方光标。进入编辑后输入会同步到多个光标。

## 动手练习

在练习文本写多行相同的 `old_name`，把光标放在词上连按 `<C-n>` 选中匹配，按 `c` 输入 `new_name`，Esc 结束；再用 `u` 撤销练习。

## 注意事项

在进入多光标模式前确认匹配范围；过宽时按 `q` 跳过不想编辑的匹配。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
