# which-key.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

显示当前按键前缀下有哪些快捷键，帮助发现映射。

## 在当前配置里怎么用

按 `<leader>` 后稍停查看下一层；`<leader>?` 打开当前模式映射列表；按 `<C-w>` 后稍停查看窗口操作。也可运行 `:WhichKey` 并查询指定前缀。

## 动手练习

按空格但先不要继续输入，阅读提示；接着输入 `f` 看文件相关命令；按 Esc 取消；再运行 `<leader>?` 搜索你记得的一段描述。

## 注意事项

提示按当前模式与 buffer 条件过滤。插件提示不代表所有 Neovim 原生命令都在 which-key 中注册。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
