# auto-session

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

按项目保存并恢复打开文件、窗口布局、目录和本配置记录的侧栏状态。

## 在当前配置里怎么用

`<leader>ws` 手动保存，`<leader>wr` 搜索并恢复会话，`<leader>wa` 切换自动保存，`<leader>wd` 删除会话。当前配置会自动创建、保存和恢复项目会话。

## 动手练习

在一个 Git 项目里打开两个文件并调整分屏，按 `<leader>ws` 保存；退出 Neovim 后从同一目录重开，观察文件和布局恢复；按 `<leader>wr` 体验会话列表。

## 注意事项

会话包含本地文件路径与窗口信息，不要提交生成的 session 数据。启动时恢复成功会直接进入会话，不显示 Dashboard。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
