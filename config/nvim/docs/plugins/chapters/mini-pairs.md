# mini.pairs

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

输入括号、引号和部分 Markdown 围栏时自动补上闭合符号。

## 在当前配置里怎么用

Insert 模式输入 `(`、`[`、`{`、引号时自动成对；跳过已有右括号；`<leader>up` 开关。

## 动手练习

在空行进入 Insert，输入 `(`、文字、`)`，观察光标是否跳过已有闭括号；试试输入引号；按 `<leader>up` 关闭后再对比。

## 注意事项

实际行为会依据光标位置和配对情况智能跳过；不适应自动闭合时可关闭。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
