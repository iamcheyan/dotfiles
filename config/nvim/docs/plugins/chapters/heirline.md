# heirline.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

绘制本配置的底部状态栏和顶部上下文栏，并响应点击交互。

## 在当前配置里怎么用

通常自动显示。观察模式、文件名、Git 状态和诊断等段；点击状态栏/上下文栏项目打开菜单，Enter/空格执行，方向键或滚轮浏览，Esc/`q` 关闭。部分项目有专门的点击区域。

## 动手练习

打开代码文件和 Markdown 文件，观察状态栏随 filetype/路径变化；点击顶部上下文栏打开层级菜单，选择一个结构跳转；用 Esc 关闭菜单。

## 注意事项

它是界面框架，具体内容由本地配置和 contextline.nvim 提供；不是单独的 LSP 或文件树。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
