# rainbow-delimiters.nvim

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

按嵌套层次为括号、方括号和花括号着色，便于辨认配对范围。

## 在当前配置里怎么用

自动生效，无快捷键。打开包含嵌套调用、table 或 JSON 的文件，观察每层括号颜色。

## 动手练习

在 Lua 文件中写 `print({ user = { name = "A" } })`，观察三层括号；将光标在括号间移动并检查对应颜色是否帮助辨认范围。

## 注意事项

需要匹配的 filetype/parser 支持；若颜色难区分，可调整主题高亮或移除该插件。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
