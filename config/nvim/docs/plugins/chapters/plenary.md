# plenary.nvim

> 公开依赖库 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

为其他 Lua 插件提供通用异步、路径、测试和函数工具。

## 在当前配置里怎么用

它是依赖库，没有普通用户命令。由依赖它的插件自动加载，例如部分 Git、搜索和测试插件。

## 动手练习

日常通过 Neo-tree、Diffview、Todo Comments 等上层插件的操作间接使用；在 `:Lazy` 中查看它被哪些插件依赖。

## 注意事项

不要因没有快捷键就误判为无用。只有删除所有依赖它的插件后才可评估移除。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
