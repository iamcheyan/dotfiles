# mini.hipatterns

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

直接在代码和文档里给十六进制颜色字面值加背景色。

## 在当前配置里怎么用

打开含 `#RRGGBB` 或 `#RGB` 的文件，自动显示色块；无命令和快捷键。

## 动手练习

在 CSS 或 Markdown 里写 `#ff8800`、`#0af` 和一个普通词，观察只有颜色值被标出；修改颜色值确认色块更新。

## 注意事项

它只负责显示颜色预览；交互式调整和格式转换请用 ccc.nvim。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
