# mini.ai

> 公开插件 · [回到插件目录](../PLUGINS.md)

## 它解决什么问题

扩展 Vim 的 `a`/`i` 文本对象，让操作按括号、函数、参数等结构选取。

## 在当前配置里怎么用

普通模式 `d` 删除、`c` 修改、`y` 复制；Visual 模式 `v` 选择。常用 `ciq` 改引号内容、`dif` 删除函数内部、`caf` 选择整个函数、`via` 选参数。

## 动手练习

在练习代码里把光标放进字符串，按 `ciq` 输入新文字；在函数体内按 `vaf` 观察整个函数选区；对一个参数使用 `dia` 删除参数并用 `u` 撤销。

## 注意事项

对象的含义依赖 parser 与 filetype。普通 Vim 引号/括号对象仍可用；新对象可先在练习文件确认范围。

## 查快捷键和帮助

在 Neovim 里用 `:verbose nmap <按键>` 查看最终映射和定义来源；按 `<leader>` 后稍等可看 which-key 提示。可用命令可用 `:command <前缀>` 查询。
